# TypeScript

TypeScript fundamentals across 6 incremental tasks, each with its own package.json, tsconfig.json, and webpack config.

---

## Tasks / Files

- **task_0**: Basic types, Student interface, rendering HTML table to DOM
- **task_1**: Classes, inheritance
- **task_2**: Type guards (isDirector), string literal types (Subjects), union types, Director/Teacher interfaces
- **task_3**: Ambient declarations, RowID/RowElement types, CRUD module with insertRow/updateRow/deleteRow
- **task_4**: Namespaces -- subjects/Teacher.ts, Subject.ts, Cpp.ts, Java.ts, React.ts
- **task_5**: Branded types -- MajorCredits and MinorCredits with brand property for nominal typing

## Key Concepts

Interfaces, types, classes, namespaces, ambient declarations, branded types, union types, type guards
